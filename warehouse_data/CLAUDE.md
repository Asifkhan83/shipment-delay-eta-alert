# CLAUDE.md — warehouse_data folder

These rules apply to this folder only.

- `vendors.csv` holds made-up practice vendor contacts. None of them are real people or real companies.
- Never add real people or real email addresses to any file in this folder.
- Every row in `vendors.csv` needs a consent value. Don't add a row without one.
- Never change the `@example.com` email addresses. That domain is reserved and can never receive mail, so no real person is ever emailed.
